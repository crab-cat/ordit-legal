# Ordit — サポート / Support

Orditは、予定とメモを端末上で扱うカレンダーアプリです。このページは無料版のサポート窓口です。アプリの一般公開状況はApp Storeの表示をご確認ください。

Ordit is a calendar app for working with events and notes on your device. This page supports the free edition. Check the App Store for public availability.

## 使い方と接続 / Using the app

アプリ内の設定から、表示するAppleカレンダーやMarkdownフォルダを選択します。接続先の原本は元の保存先に残ります。必要な権限を許可していない場合やファイルへアクセスできない場合は、該当する接続の設定を確認してください。端末のカレンダー同期やWidget・Live Activityの更新時刻はOSの制御も受けます。

Choose the Apple calendars or Markdown folders to display in Settings. Original data remains in its original location. Check the relevant connection settings when permissions or file access are unavailable. Calendar synchronization and Widget/Live Activity refresh timing also depend on the operating system.

## 不具合や問い合わせ / Report a problem

このリポジトリの [Issues](https://github.com/crab-cat/ordit-legal/issues) からご連絡ください。端末の種類、OSバージョン、再現手順、期待した動作と実際の動作を記載してください。予定・メモの本文、個人のカレンダー名、メールアドレス、トークン、パスワードを投稿しないでください。画面写真は個人情報を隠してから添付してください。公開Issueへの投稿にはGitHubアカウントが必要です。アプリの利用にGitHubアカウントは不要です。

Use this repository's [Issues](https://github.com/crab-cat/ordit-legal/issues). Include the device type, OS version, steps to reproduce, and expected versus actual behavior. Do not post event or note contents, private calendar names, email addresses, tokens or passwords. Redact personal information in screenshots. Posting a public issue requires a GitHub account; using the app does not.

## お知らせと保守 / Notices and maintenance

告知機能を備えた版では、起動・復帰時に、一定間隔を空けて公開のお知らせを取得します。設定の「サポートとお知らせ」から手動でも確認できます。通常時は告知バナーを表示しません。案内を読むために課金やログインは必要ありません。

Versions containing the notice feature check a public notice file periodically when opened or resumed. You can also check manually in Settings → Support and notices. No banner is shown during normal operation. Reading notices does not require payment or sign-in.

通信できない場合は、取得済みの案内と端末内の機能を利用できます。新しい告知を完全オフラインで届けることはできません。告知は案内専用で、任意のコード実行、購入の開始、利用者の予定やファイルの削除、ローカル機能の遠隔停止は行いません。

When offline, previously saved notices and local features remain available. New notices cannot reach a completely offline device. Notices are advisory only: they cannot execute arbitrary code, initiate purchases, delete your events/files, or remotely disable local features.

提供内容に変更や終了予定がある場合は、対応版のアプリ内告知とこの公開窓口で、対象・時期・利用者に必要な操作を案内します。これはサービス終了の告知ではありません。現時点の告知状態は通常運用です。

If availability changes or a retirement is planned, notices in supported app versions and this public support channel will explain the scope, timing and any required action. This is not a retirement announcement. The current notice state is normal operation.

## データを守る / Protecting your data

Appleカレンダー、選択したMarkdownファイル、任意に接続したサービスの原本は、各保存先で管理してください。バックアップは元の保存先の方法を利用してください。問題の切り分けのために、アプリや原本データを不用意に削除しないでください。アプリ独自の全設定・全接続先を一括書き出す機能を保証するものではありません。

Manage and back up original calendars, selected Markdown files and connected-service data at their original locations. Do not delete the app or source data merely to investigate a problem. This guidance does not promise a universal export of every app setting or connected service.
